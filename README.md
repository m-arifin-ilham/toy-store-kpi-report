# ✨Dummy Store KPI Report✨

I made a simple and interactive KPI report of a dummy toy store sales data using Power BI and Tableau. The report can be used by the leadership team to monitor key business metrics and high-level trends. Inside, I made three KPI visual cards of total orders, revenue and profit by month. I showed a barplot of total orders by category and a line chart of total revenue per month. All of the visuals inside can be filtered by selecting the type of store location and by clicking on the line to filter by month. 

The PowerBI report can be accessed in the file "_Toy Store KPI Report.pbix_". If you want, Tableau file itself can be accessed in the "_Tableau - Toy Store KPI Report.twbx_" file or by accessing the following URL (https://public.tableau.com/views/ToyStoreKPI/Dashboard). Also, the data I used can be accessed in the folder "Maven Toys Data", in which, you can find the product, sales, store data and calendar information. Additional information about the data itself and the fields is provided in the file "_data_dictionary.xlsx_". The file "_inventory.xlsx_" is just additional.
